现场核对日期：2026-10-16（北京时间）。本次仅迁移电脑端连接、核对并启动设备服务；助手未下发舵机运动、扭矩切换或动作组回放。

## 现在可以怎样使用

网页已经运行：<http://192.168.137.100:8080>。Safari 页面可以打开，用户已确认视频显示正常。

下次接好网线、开发板启动后，双击项目根目录的 `启动机械臂网页.command`。
入口显式启用实机网页和 ROS2 纯计算节点，启动本身不读取舵机或运动。网页中的单关节“确定”、姿态执行按钮及完整抓取执行按钮仍按当次明确参数授权。

启动入口会重新读取本地规则文件，对比设备上已审阅的 28 项规则和源码指纹；设备代码变化时拒绝自动启动，须先审阅变化并更新清单。它不上传本地代码，不覆盖配置，不自动结束进程或删除锁。
现有网页已经运行时只查询状态，避免重复启动；现有服务模式与请求不一致时报告并停止，不自动切换。

终端方式，在本项目根目录运行：

```bash
/usr/bin/python3 -B mac_tools/service.py --start --real
```

仅查询、核对而不启动：

```bash
/usr/bin/python3 -B mac_tools/service.py
```

省略 `--real` 的启动请求使用模拟模式。入口脚本只依赖 macOS 自带的 Python 标准库和 SSH，不使用 `.local_deps` 或本地虚拟环境。
