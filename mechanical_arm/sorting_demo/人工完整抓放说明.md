# 人工指定目标的完整抓放

用户最新选择为按模型计算、不放十字纸。本地无纸模式已实现，见[无标定纸操作说明](无标定纸方案与参数来源.md)。当前设备离线待部署；下文纸张与实测准备保留为原有方式，无纸模式无需执行这些步骤。定位精度及真实抓取验收另记。

入口：`http://192.168.137.100:8080/manipulation`。本页不调用颜色或物体识别。

## 当前证据边界

软件、假设备测试、部署检查与现场验收分别记录。出现网页和三维模型不代表实机已标定。
已由用户提供：方块30×30×30毫米，十字总长、总宽30毫米，线宽2毫米；夹爪机械开口0～60毫米；第一个转动关节中心离桌面80毫米。
课程模型中joint1中心Z=64毫米，按此参考点对齐后桌面Z=−16毫米，方块顶面Z=14毫米，已写入独立配置的桌面高度。该数值来自用户量尺与课程模型组合，仍需定位误差检查。
机械最大开口不等于当前`gripper.open`目标到位后的实际净宽；当前目标开口、工具偏移及相机位置等仍待核对。新任务要求真实完整读数；旧pickup_only例外不扩大。
模型的关节间距和外形包络候选由`derive_manipulation_dimensions.py`计算，保存在`models/manipulation/dimensions.json`。不需要操作者重新量每个连杆或计算包络半径。候选仅包含文件中的静态外形，安装附件、夹爪开合和真实坐标对齐须核对，不能直接登记为现场证据。

## 第一次准备

1. 在原手动页面检查真实关节范围和夹爪目标；已有目标不自动更改。恢复观察姿态前须核对按钮显示的角度、顺序和用时，并当次确认。
2. 先按[现场清单](现场测量与验收清单.md)的简单步骤收集现场信息，再展开“首次准备”。桌面Z已根据用户报告计算为−16毫米，不需重复填写；核对允许取放区域、运动空间、实际张开目标的净宽、误差阈值和运动高度。所有长度为毫米，舵机目标为整数度。
3. 核对模型零点、转向、夹持中心相对link5的偏移和方向。`jaw_axis_tcp`表示工具坐标中的夹爪闭合方向，必须为与工具Z轴垂直的单位向量。工具Z轴定义为接近方向；本版完整任务要求接近时朝下，无法实现时拒绝。
4. 先使用模型提取的底座盒、连杆和工具外形候选，再根据真实安装核对和扩展，不要求操作者手算包络。底座盒字段为`base_box_mm`，使用`center_mm`及`half_size_mm`。运动空间应容纳实际连杆、工具和携带方块的完整包络及检查余量。`tool_boxes_mm`相对link5，每项为`{"center":[x,y,z],"half_size":[hx,hy,hz]}`。必须覆盖夹爪开合、摄像头和支架。额外固定障碍按底座坐标填入`obstacles`，使用`center_mm`、`half_size_mm`；不建模未知障碍。
5. 方块姿态照片、示教角度和读数均保留。模型核对至少记录三个不同姿态的真实夹持中心坐标，另留至少一个独立姿态。每个姿态先手动确认到位、冻结记录，再输入明确关节目标和实测XYZ。禁止用计算坐标填写实测字段。

## 临时十字纸标定

- 默认纸坐标原点是十字中心，+X向右、+Y向上。四个特征点依次为：左端面中点(-15,0)、上端面中点(0,15)、右端面中点(15,0)、下端面中点(0,-15)。这些是根据用户报告尺寸生成的点选模板，须对照实纸；不是只点中心。
- 如果实际纸上还有更大的、可测的矩形外框，可将模板换为外框四角的真实纸坐标。30毫米十字在图中可能较小；点选误差过大时应改善采样和特征跨度，不以放宽夹持余量检查替代。
- 拍10～30幅不同倾斜视角，覆盖图像不同区域；每幅重新冻结并按同一编号点选全部特征，加入样本，再计算内参。无需用机械臂移动相机：可以保持机械臂不动，手持纸张改变位置和倾角。采样时仍保留真实关节和分辨率证据。
- 将纸临时平铺桌面，测量纸原点相对底座的XYZ及纸坐标X轴相对底座X轴绕Z方向。回到最终观察姿态，冻结、点特征，保存观察标定。
- 桌面和方块顶面各采至少三个不共线、未参与拟合的实测位置检查，点选图像点并输入实际XY。
- 先保存测量，再登记模型和定位核对。所有核对通过后可移走纸；取物和放置使用保存的相机外参，无需纸仍出现在图中。底座、桌面、安装、焦距或分辨率改变须重新核对相关标定。

## 空载验证

1. 在固定观察姿态冻结图像。拖框圈住方块，点顶面中心，再点顶面同一条边的两端；框中心不会自动充当顶面中心。选择固定放置点或点桌面空放置中心。
2. 勾选场景核对，生成空载验证计划，仅计算。查看三维姿态、关节目标、用时和顺序。
3. 移走方块，确认夹爪空载，按顺序点击每步“预览并批准这一步”，核对明确参数后确认运动。每步有一次性令牌，失败不重试，不跳步；页面关闭或重启后不自动恢复执行。
4. 全部步骤真实下发和回读完成，现场确认路径后登记通过。至少五个分散且不共线的取物位置；改变标定会使这些记录失效。
5. 空载证据不会自动证明带块转移或任意新目标路径已实机验证。首次带块任务从已核对区域开始，仍由操作者审阅和确认。

## 日常完整抓放

冻结图像 → 框选 → 点顶面中心 → 点同一顶面边两端 → 选放置位置 → 完整预览 → 核对并当次确认。

完整计划含张开、接近、夹持、抬升、转移、放置、松爪、撤离、返回观察，全部事先显示。确认后不再识别或取新相机画面，只按冻结目标核对计划、代码、配置和真实读数。
目标或放置区域变化应取消旧计划并重新冻结。冻结目标和执行预览均有限时约束。

记录分为指令下发、回读验证和人工结果。没有夹持传感器，无法自动证明夹空、滑落或最终放置正确。执行结束应人工记录成功或失败。
失败停止后续下发，不自动重读、重试、回零、松爪或复位。Ctrl+C和网页取消不能撤回已发出的运动。

## 视觉接入约定

人工和外部视觉共用以下目标。输入是原图像素，不能提交CSS缩放后的坐标；顶面方向不能由轴对齐检测框直接代替。

```json
{
  "source": "manual 或 vision",
  "task_mode": "pickup 或 pick_place（省略时兼容原完整抓放）",
  "frame_id": "服务生成的冻结画面编号",
  "image_size": [640, 480],
  "block_size_id": "block",
  "bbox": ["左", "上", "右", "下"],
  "center_px": ["u", "v"],
  "edge_px": [["u1", "v1"], ["u2", "v2"]],
  "destination": {"kind": "fixed", "name": "已保存名称"}
}
```

另一种放置输入为`{"kind":"pixel","pixel":[u,v]}`，表示桌面放置中心。方块尺寸取已核对的配置，本版仅同尺寸正方形顶面方块。

`GET /control/status`获取同源CSRF令牌；所有POST携带它，并要求同源Origin。

| 接口 | 用途 |
|---|---|
| GET `/manipulation/status` | 准备状态、配置、空载进度、模型资源 |
| POST `/manipulation/capture` | 冻结原图和真实读数，不运动 |
| POST `/manipulation/target` | 将统一目标转换为底座中心、方向及放置点，不运动 |
| POST `/manipulation/preview` | `target`、`scene_confirmed`、`dry_run`；完整计算与预览，不运动 |
| POST `/manipulation/step` | `draft_id`、`index`、`empty_confirmed`；仅预览当前空载步骤 |
| POST `/control/execute` | 本次`token`及`confirmed=true`，唯一执行入口 |
| POST `/manipulation/invalidate` | 撤销待执行预览，不停止已下发运动 |
| POST `/manipulation/validation` | 真实空载逐步完成后的人工登记 |
| POST `/manipulation/result` | `task_id`、`result`、`note`，人工结果 |
| GET `/manipulation/acceptance` | 当前标定版本的真实验收统计 |

`settings`采用完整`setup`与`expected_sha256`乐观并发核对；`intrinsics`输入`setup`及采样列表；`anchor`输入`setup`、`frame_id`及`expected_sha256`。
外部视觉只需替换目标生成适配器，仍使用服务冻结编号和同一规划、确认、执行流程，不直接提交舵机命令。

`pickup`任务可以省略`destination`，结束时保持夹持。方向端点仍必填；相机投影姿态由服务按冻结编号从真实记录取得，调用方不应填写内部`_frame_joint_angles`字段。无纸准备接口为`POST /manipulation/prepare-cad`，输入冻结编号、明确观察目标、相机参数来源及配置期望散列；只保存候选，不运动。

## 部署与验收

- 用户数据和设备端配置为准。仅部署代码、结构资源，以及设备尚不存在的新完整抓放默认配置。原数据与代码先备份到`/root/jjt/backups`。
- 测试夹具与合成标定绝不部署为实测数据。默认未知值为空、核对关闭。
- 本地假设备测试不导入Arm_Lib，不使用真实相机；现场测试独立按运动审批进行。
- 固定点和图中点选放置分别先连续成功三次，再各连续记录十次，至少八次人工确认正确抓放。异常、失败及未确认结果保留；模拟不能计入实机统计。
- 改变标定版本后旧验收记录保留，但不计入当前版本。
