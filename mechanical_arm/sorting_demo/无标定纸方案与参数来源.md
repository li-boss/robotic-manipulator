# 当前操作：按冻结姿态直接抓放（2026-10-23更新）

相机随机械臂运动，新人工模式使用每幅冻结图的完整真实六关节读数计算光学位姿和路径起点，不要求恢复固定观察姿态，也不要求夹爪事先张开。起始夹爪须空载，张开10°是本次完整计划中的明确动作。

日常：冻结画面 → 选择拖外围框或四角框选 → 点顶面中心（放置任务另点桌面空位置）→ 生成计划 → 核对所有步骤和参数来源 → 点击确认执行。

旋转或透视顶面可点击“四角框选”，从同一条边的两个端点开始，顺时针或逆时针沿顶面轮廓点四角；第一、二点明确指定方向，再单独点顶面中心。拖框方式也支持斜放：外围矩形只需包住方块，无须贴合斜边，随后仍须手点中心及同一条顶面边两端。框不代替物体尺寸或中心，修改选点会使原计划失效。视觉适配器可选择增加`outline_px=[[u1,v1],...,[u4,v4]]`，按轮廓顺序提供四角；旧目标结构继续可用。

当前CAD相机参数属于估算。投影边长与已知30毫米不同会在计划和最终确认中显示定位诊断，不再直接认定人工标注错误或阻止计划。不会通过缩放坐标、更改方块尺寸或伪造标定来消除差异。真实标定模式仍执行边长一致性检查；两种模式都保留像素/方向退化、工作区、不可达、关节范围和全路径碰撞检查。首次所需模型参数自动生成，参数来源与完整计划一起确认，不要求另做全局采用。不会在标注或生成时自动运动。

整批执行不再以五个位置的空载验收为前提。空载逐步功能保留为可选检查，是否做过、结果如何继续如实记录；解除前置门槛不等于实际精度或抓放成功率通过验收。完成放置后撤离，不再自动返回固定观察姿态。

“任意姿态”指不限定一个观察姿态。机械臂必须停稳，能读齐真实角度，目标顶面和所选桌面点须在视野内且可投影，起始位置与完整路线须满足范围和碰撞检查。视线与桌面平行、目标在相机后方、碰撞或不可达时会拒绝。冻结后机械臂或方块移动须重新冻结选点。保留120秒冻结目标与确认令牌时限。

当前原配镜头没有已匹配的真实内参，默认仍是明确标注的110°视场估算；三维结构不能证明像素定位或真实夹持已达精度。高级参数可更换成实际相机参数。原手动、保存姿态、示教及pickup_only规则不受此模式影响。

以下为此前固定观察/空载门槛的历史说明；当前新入口以上述随臂模式为准。

# 不放十字纸：本轮确认与尚缺参数

用户最新要求优先：实物安装按提供的三维模型处理，取消要求用户放十字纸、重复测连杆和相机支架。此前纸张采样流程保留为可选历史方法，不再作为所选方案。

## 已确认

- 用户：夹爪角度越小开口越大；10°对应60毫米；170°基本闭合。只记录两端点及方向，不假定中间传动为线性，也不自动修改旧任务的90°/127°目标。
- 用户：课程原装USB相机、镜头未更换；其他安装与三维模型一致。
- 本地六视图：link4.STL含相机和支架结构；link5.STL含夹爪。见implementation_backups/manipulation_20261016/tool_mesh_views.png。先前文档“模型不包含相机/夹爪”的描述已修正。
- 关节位置、外形尺寸、静态包络候选已从URDF与STL提取，文件为models/manipulation/dimensions.json。

## 几何和成像参数各从哪里取得

| 内容 | 来源和状态 |
|---|---|
| 连杆原点、关节轴、零件外形 | 课程URDF及六个STL可读取 |
| 相机壳体和支架在link4的位置 | 网格中可查看和拟合；没有单独命名的相机光学坐标系 |
| 镜头有效光心、图像轴方向 | 不能把壳体中心直接当作有效光心；驱动图像方向也须明确 |
| 相机内参、镜头畸变 | 当前提供的文件未包含；安装与模型一致不产生这些数值 |
| 相机规格 | 课程资料：640×480、110°视场角、可手动调焦；未注明视场角方向，未提供内参矩阵及畸变系数 |
| 实际抓放精度 | 尚无本系统的现场验收数据；模型计算不能代替这项结果 |

例如，若暂时假设无畸变、方形像素，640×480相机的110°若指水平视场，等效焦距约224像素；若指对角视场，则约280像素。这两者相差25%。两种均是标称规格的假设解释，不能擅自选一项当作已知真值。

不放纸的可行来源包括：该相机对应分辨率与镜头设置下的厂家内参、设备已有的相机参数文件，或用已知30毫米方块的图像约束估计参数。最后一种仍属于无纸相机参数估计，需说明假设并验证误差，不能称为只从STL计算。

参考：[OpenCV相机模型](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)分别列出安装变换、内参和畸变；缺失的部分不能用安装变换替代。

## 已实现的无纸流程

本地代码已接入无纸分支：从已核对散列的模型生成相机安装、夹持中心和碰撞包络候选，不要求纸张或手工填写工程矩阵。相机投影采用每幅冻结画面的原始关节读数；相机安装在link4，5号夹爪旋转不会错误地带动相机。保存的观察目标用于核对起始条件，不代替原始读数。

支持“只夹取并抬升”和完整抓放。“只夹取”结束后保持夹持，不自动松爪或返回。旋转方块仍需点同一顶面边的两个端点；框和中心不能唯一确定方向。人工/未来视觉目标共用同一接口。

规划器枚举0°、15°、30°、45°径向接近候选，使用解析种子与数值逆解，整数化后复核位置、方向、关节范围和完整路径。每个实际逐关节中间段都有连续扫掠检查；必要的中间姿态也列入当次有限计划，不在执行时临时搜索或自动重试。带块搬运保持夹持后的腕部滚转关系，放置姿态不能保持平放时拒绝。

CAD碰撞包络由完整三角网格分解成69个盒候选，覆盖相机、支架和夹爪最大开口候选。桌面距离检查使用网格凸包支撑点，避免包围盒空隙造成误判；凸包只在本地用SciPy预处理，设备无需安装SciPy。网格候选不证明线缆或夹爪真实传动扫掠已经实测。

采用模型候选不会将`model_reviewed`或`calibration_reviewed`改为实测通过；`cad.assumptions_confirmed`仅表示采用页面明确列出的候选。修改实际参数清除空载验证和采用状态；浏览器将1.0写成1不会改变版本。

实机任务仍要求完整真实读数、硬件锁、预览版本核对、一次性请求去重和当次完整参数确认。先完成至少五个分散位置的真实空载逐步路径，才开放整批真实任务；模拟可以直接走完整假设备流程，永不计入实机验收。

## 你使用时的顺序

1. 开发板连接后打开`/manipulation`。先在原手动页核对已保存观察姿态的关节、顺序及用时，确认到位。
2. 回到本页冻结画面。在“无标定纸：从模型准备”选择已有观察姿态，点击“填入所选姿态”，这里只填目标、不运动。
3. 选择相机参数来源。已有真实内参时导入；暂缺时可明确选择110°的某种视场解释进行估算。点击“根据冻结姿态生成模型候选”。
4. 查看候选中的夹持中心、张开10°、原配置夹持角度、抓取及转移高度和空域假设，核对后勾选采用。候选高度是计算方案，不能称为实测安全高度；不符合现场时在高级参数中调整并重新采用。
5. 新模式的观察起始条件要求6号为10°。需要调整时，在原手动页检查该次明确角度与用时并确认；再回新页重新冻结。助手不自行执行这一步。
6. 拖框圈住一块30毫米方块，点顶面中心，再点同一顶面边的两个端点。只夹取任务无需放置点；完整抓放还要选择保存点或点桌面放置中心。点击“计算目标空间位置”。
7. 先生成空载计划，查看三维和所有关节参数；移走方块后逐步确认验证。空载步骤之间不要重新冻结、改配置或另行手动运动，否则原计划会失效。失败后不自动恢复或跳步。
8. 完成规定空载验证后重新放块、冻结和选点，生成本次任务预览并当次确认。结束后记录人工成功或失败；“回读符合目标”不等于传感器检测到夹牢。

## 可直接导入的相机参数

JSON结构：`image_size`为当前分辨率，`matrix`为3×3内参，`distortion`为5项畸变系数，`source`注明实际来源。导入分辨率必须与冻结图相同，不自动裁切或缩放，不截断其他畸变模型。

设备连接后，可先只读查找已有参数：

```bash
/root/miniconda3/envs/ros-arm-env/bin/python -B /root/jjt/sorting_demo/inspect_camera_parameters.py
```

脚本不打开相机、不读取舵机、不运动；候选存入`/root/jjt/sorting_demo/logs/camera_parameters`，不会自动覆盖运行配置。来源、分辨率和镜头设置须对应当前原配相机。已有文件未必属于这台相机。
