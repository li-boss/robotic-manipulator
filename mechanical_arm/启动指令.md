# Mac 启动（2026-10-16 已现场连接）

双击项目目录中的 `启动机械臂网页.command`，检查通过后打开网页。
该入口显式启用实机网页；启动不读取舵机、不发送运动，运动由用户在网页上当次确认。
入口核对已审阅设备源码指纹，服务已运行时只检查，不重复启动、不自动重启。

也可在项目根目录的终端运行：

```bash
/usr/bin/python3 -B mac_tools/service.py --start --real
```

仅检查（不启动、不运动）：

```bash
/usr/bin/python3 -B mac_tools/service.py
```

网页：<http://192.168.137.100:8080>。
完整环境检查和注意事项见 [Mac运行说明.md](Mac运行说明.md)。

原始设备启动命令如下，使用前须重新核对规则、设备实际源码、参数、现有进程和锁；不要重复启动：

```bash
ssh root@192.168.137.100 '/root/miniconda3/envs/ros-arm-env/bin/python -B /root/jjt/sorting_demo/start_service.py --enable-real-control --enable-ros-planner'
```

Mac 已加入本机公钥，使用系统默认密钥；不再使用原来的 Windows 私钥路径。
