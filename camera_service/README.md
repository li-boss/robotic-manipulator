# 相机采集（A）

板端 Atlas USB 摄像头由现有服务独占采集；A 服务可在 Windows 使用 `--mode camera --source 'http://192.168.137.100:8080/stream.mjpg'` 读取 640×480 MJPEG 流。正式模型仍在 Windows CPU 推理，原图及元数据按 `frame_id` 供 D 读取。可选彩色顶面中心由 `--top-face` 显式开启。启动、预览、停止命令见 [A 运行说明](../docs/a/运行与对接说明.md)。

HTTP MJPEG 读取使用 FFmpeg 打开／读取超时并连续排空，失败时将帧源标为不可用，不把最后一帧重新发布。`captured_at` 是 A 电脑发布画面的时间；板端未提供源帧序号和曝光时间，仍需用可见画面变化实测上游是否积压或冻结。全图人工审查、黄色顶角诊断和当前限制见 [顶面定位验证](../docs/a/顶面中心定位验证.md)。
