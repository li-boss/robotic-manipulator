# 表情手势识别局域网接口（`jjt-gesture/1`）

> 给表情手势同学。结构和方块识别（`docs/方块识别局域网接口.md`）一样：**只有控制同学的 Mac 连接开发板**；你的模型跑在你自己的电脑上，通过局域网收一帧图、回“这一帧是什么表情/手势”。你不需要、也不应该连接开发板或改开发板上的文件。

---

## 1. 整体怎么走

```
你的电脑（局域网）                    控制同学的 Mac（唯一连开发板）                       开发板（不变）
                                       pc/run_gesture_dance.py（地址见 pc/lan_config.json）
                                         ① 取一帧（默认开发板摄像头快照） ◄──────────────── /api/v1/frame.jpg
 识别服务（你的模型）◄── ② POST /recognize（JPEG）
                    ── ③ 返回 {label, confidence} 或 null ──►
                                         ④ 连续多帧确认（防抖）→ 按映射选舞蹈 ─────────────► /api/v1/gesture
                                                                                             按网页开启的会话授权跳舞
```

- 你只负责“一帧图 → 表情/手势标签 + 置信度”。连续几帧确认、标签对应哪支舞、冷却时间、提交给开发板，全部在 Mac 上；能不能跳由开发板按网页上开启的“表情手势跳舞”会话决定。
- 你的服务**不能**指定舞蹈、不能触发运动；回复里出现协议之外的字段（例如舞蹈名、关节角度），Mac 端整次拒绝并停止程序。
- Mac 端每秒发几帧，所以识别要快（建议单帧 < 300 ms）。

---

## 2. 你要跑的服务

用仓库里的参考服务，把你的识别器类挂上去，不用自己写 HTTP：

```bat
REM 在仓库根目录，用你自己的模型环境
python pc\gesture_server.py --recognizer gesture.recognizer:DanceRecognizer --host 0.0.0.0 --port 8101
```

- `--recognizer`：`模块:类名`，类继承 `pc/gesture/base.py` 的 `GestureRecognizer`，实现 `recognize(image) -> GestureEvent | None`（image 为 BGR numpy 图）。现有的 `DanceRecognizer` 就是这个形状。
- 本地自检：`python pc\gesture_server.py --recognizer ... --selftest 图片.jpg`，打印将要返回的 JSON。
- Windows 防火墙放行 8101 入站；把你在局域网里的 IP 告诉控制同学（他写进 `pc/lan_config.json` 的 `gesture_url`）。

---

## 3. 协议

### 3.1 `GET /health`

```json
{"protocol": "jjt-gesture/1", "ready": true, "model": "DanceRecognizer v2"}
```

### 3.2 `POST /recognize`

请求：Body 为 JPEG（`Content-Type: image/jpeg`）；请求头 `X-Frame-Id`（32 位十六进制，原样带回）、`X-Image-Width`、`X-Image-Height`。

成功返回（HTTP 200）：

```json
{"protocol": "jjt-gesture/1", "frame_id": "与请求头相同", "model": "DanceRecognizer v2", "ms": 42.0,
 "event": {"label": "smile", "confidence": 0.87}}
```

- 没识别到时 `"event": null`（这个字段必须有）。
- 顶层只允许 `protocol`、`frame_id`、`model`、`ms`、`event`；`event` 只允许 `label`（1～64 字）和 `confidence`（0～1）。
- 标签名由你们定（现在用 `smile`、`palm`、`fist`、`like`、`ok`）；对应哪支舞由 Mac 端 `--map` 决定（默认 `smile=COURSE_DANCE_ROUTINE,palm=MUSIC_DANCE_ROUTINE`）。

出错返回 HTTP 4xx/5xx 和 `{"error": "原因"}`。Mac 端把网络错误/超时当作“这一帧没识别到”（1 秒后再试，不会因此跳舞）；回复格式不合协议则停止程序。

---

## 4. 联调

1. 你：`--selftest` 用几张图确认标签对。
2. 你：启动服务，浏览器打开 `http://127.0.0.1:8101/health` 看到 `ready: true`。
3. 控制同学：把你的 IP 写进 `pc/lan_config.json` 的 `gesture_url`，`curl --noproxy '*' http://你的IP:8101/health` 能通。
4. 控制同学：在开发板 `/modes` 开启“表情手势跳舞”会话，Mac 上运行 `python pc/run_gesture_dance.py`。

不再需要：在你电脑上直接运行 `run_gesture_dance.py` 连接开发板。
