## 3. 第一次切换步骤

1. **确认设备空闲**：网页上没有任务在执行，没有人在用机械臂。

2. **备份设备**（只读打包）：

```bash
ssh root@192.168.137.100 'cd /root && tar czf /root/jjt_backup_$(date +%Y%m%d_%H%M%S).tgz jjt --exclude=jjt/calibration_runtime'
```

3. **上传新代码**（不带 `board/data/` 里的模板，避免和设备上的真实配置冲突）：

```bash
rsync -av --exclude 'data/' --exclude '__pycache__' board/ root@192.168.137.100:/root/jjt/board/
```

```bash
rsync -av tools/migrate_device_data.py root@192.168.137.100:/root/jjt/tools/
```

```bash
rsync -av AGENTS.md 机械臂操作准则.md root@192.168.137.100:/root/jjt/
```

4. **迁移数据**（复制，不删除旧文件；先看再执行）：

```bash
ssh root@192.168.137.100 'python3 /root/jjt/tools/migrate_device_data.py'
```

```bash
ssh root@192.168.137.100 'python3 /root/jjt/tools/migrate_device_data.py --apply'
```

   迁移包括 `arm_config.json`（原 `arm_playground/config.json`）、姿态按钮、`web_control.jsonl`（防止重启后重复执行的去重记录）、抓放配置、手眼标定、九点资料和所有冻结画面证据。

5. **放入跳舞模板**（设备上没有时才放）：

```bash
ssh root@192.168.137.100 'test -e /root/jjt/board/data/dances.json' || rsync -av board/data/dances.json root@192.168.137.100:/root/jjt/board/data/
```

6. **停止旧服务**：先查 PID（`ps -eo pid,args | grep /root/jjt/sorting_demo/`），确认设备空闲后再结束旧的 `server.py` 和 `ros_planner.py`。不要删除硬件锁文件，除非确认没有任何程序在控制机械臂。

7. **更新本地指纹清单并启动**（启动本身不运动）：

```bash
python3 -B tools/mac/service.py --update-reviewed
```

```bash
python3 -B tools/mac/service.py --start --real
```

   或者双击项目根目录的 `启动机械臂网页.command`。启动器会先核对设备上的规则与代码指纹和本地清单一致。

8. **验收（不运动）**：打开首页、框选抓放页、标定页，确认摄像头画面、模式为“实机”、抓放资料检查通过、“九点参考”状态与切换前一致。

切换失败时：停止新服务，按原命令启动旧服务即可（旧目录未改动）：

```bash
ssh root@192.168.137.100 '/root/miniconda3/envs/ros-arm-env/bin/python -B /root/jjt/sorting_demo/start_service.py --enable-real-control --enable-ros-planner'
```

## 4. 日常启动

```bash
python3 -B tools/mac/service.py --start --real
```

只查看状态（不启动）：

```bash
python3 -B tools/mac/service.py
```

在开发板上直接启动（不加 `--enable-real-control` 为模拟）：

```bash
ssh root@192.168.137.100 '/root/miniconda3/envs/ros-arm-env/bin/python -B /root/jjt/board/start_service.py --enable-real-control --enable-ros-planner'
```

## 4.1 电脑端规划（提速，可选）

网页服务默认先请求 `http://192.168.137.101:8095`（`pc/plan_server.py`）。连不上时会自动改用开发板本地计算，所以电脑端不开也能用。
- 换地址：在 `server.py` 启动参数里加 `--pc-planner http://IP:端口`。
- 完全不用：`start_service.py --no-pc-planner`。

电脑端的代码必须与开发板是同一版本：更新 `board/` 后，电脑上也要拉到同一版本。

3. `python3 -B tools/mac/service.py --update-reviewed`，然后重启服务。
