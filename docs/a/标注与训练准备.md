```powershell
cd G:\robotic-manipulator
py -3.10 -m venv data\a_blocks\.venv-label
git clone https://github.com/HumanSignal/labelImg data\a_blocks\tools\labelImg
& data\a_blocks\.venv-label\Scripts\python.exe -m pip install PyQt5 lxml
cd data\a_blocks\tools\labelImg
& ..\..\.venv-label\Scripts\pyrcc5.exe -o libs\resources.py resources.qrc
& ..\..\.venv-label\Scripts\python.exe labelImg.py "G:\robotic-manipulator\data\a_blocks\annotation_work" "G:\robotic-manipulator\configs\a_confirmed_classes.txt"
```

如果 `pyrcc5.exe` 不在该位置，在隔离环境的 `Scripts` 目录中查找它；若该归档工具无法在本机正常启动，先报告实际报错，再改用当前维护的标注工具，不要换标注格式或重做图像。软件打开后：确认类别列表顺序；将工具栏的 `PascalVOC` 切到 `YOLO`；打开标注工作区；按 `W` 框整个积木、选择对应外观类别、`Ctrl+S` 保存，按 `D` 下一张。工具生成的 `classes.txt` 必须逐行与 `configs/a_confirmed_classes.txt` 一致。请勿中途调换类别顺序。[LabelImg 官方使用说明](https://github.com/HumanSignal/labelImg#steps-yolo)列出了格式切换与快捷键。

标注检查命令（确认已有标签后运行）：


## 后续数据划分、补拍与训练路线

先在[分组与划分模板](数据审查/分组与划分模板.csv)填写拍摄批次、场景组和用途；相邻帧、同一摆放方式及近似候选不能跨训练/验证/测试。现有图片拍摄批次无法独立证明，建议**另一天或另一次重新摆放并拍摄**的图片留作独立测试集。`train/val/test` 划分与类别覆盖确认后，才将人工核验的图片与同名 YOLO 标签整理为 `images/train|val|test`、`labels/train|val|test`，由 `data.yaml` 固定类别顺序。[Ultralytics 官方数据格式](https://docs.ultralytics.com/datasets/detect)要求每图同名标签、零起始类别 ID 与归一化 `cx cy w h`。增强只作用于训练集。

补拍至少包括：无积木工作区；每种颜色在中心、四角及边缘；不同旋转角、侧面朝向；两至四块相邻或轻度遮挡；比现有画面更暗/更亮但符合实际部署的光照；至少一次独立拍摄批次。保持相机安装和对外原图坐标约定，记录 `camera_id`、分辨率与布局版本。独立测试集要有每一类和空场景，不能从训练视频相邻帧抽取。

本地训练**暂定**以 COCO 预训练的轻量 `YOLOv8n` 检测模型微调作首个基线，因为本机 8 GB GPU 可尝试小 batch，且项目方案原本提出 YOLOv8；准确可用 batch、耗时与显存必须实际测。PyTorch 的 Windows/CUDA 安装命令应按[官方安装选择器](https://pytorch.org/get-started/locally/)选择相容版本，放入单独 `.venv` 并记录 `pip freeze`、`torch.cuda.is_available()` 和 `nvidia-smi`。Ultralytics 的[YOLOv8 文档](https://docs.ultralytics.com/models/yolov8)确认 `yolov8n` 可用于检测。当前未安装、未下载预训练权重、未训练。

正式训练前做 20 张人工标注的小规模流程检查，再完成全量人工标注和分组划分。每次保留类别文件、`data.yaml`、图片清单/哈希、分组表、训练参数、依赖版本、`best.pt` 和验证输出。精度以独立测试集的 mAP@0.5、各类 AP、精确率和召回率实测；训练设备的速度不代表最终设备的速度。

Atlas 200I DK A2 仅是课程背景，不代表实际最终设备。若后来确定要在 Atlas 上推理，须先确认板卡、系统、CANN/ATC 版本和模型算子，再按[昇腾官方开发文档](https://www.hiascend.com/document/detail/zh/Atlas200IDKA2DeveloperKit/23.0.RC2/Application%20Development%20Guide/aadgp/aclpythondevg_0001.html)与对应版本工具链验证导出和 `.om` 转换；不能承诺任意 `.pt` 或 `.onnx` 都可直接使用。
